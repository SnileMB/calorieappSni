<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| service worker → all origin requests | The SW can intercept every fetch on the origin, including authenticated Supabase calls |
| precached assets → offline execution | Precached JS executes even when the network (and any server-side revocation) is unreachable |
| manifest / start_url → installed app identity | The installed app launches whatever `start_url` points at, outside normal tab context |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-20 | Information Disclosure | Service worker caching auth/API responses | mitigate | No `workbox.runtimeCaching` rule is configured; `generateSW` precaches only static build output (JS/CSS/HTML/icons). Task 1 acceptance criteria fail if `runtimeCaching` appears in `vite.config.ts`. Supabase responses and JWTs are never written to the Cache Storage API |
| T-01-21 | Tampering | Stale precached bundle serving outdated auth logic | mitigate | `registerType: 'autoUpdate'` with Workbox `skipWaiting`/`clientsClaim` semantics means a new deploy replaces the precache on next load rather than pinning users to an old bundle indefinitely |
| T-01-22 | Spoofing | Manifest `start_url` / scope | mitigate | `start_url` is the same-origin root `/` and `display: standalone`; no cross-origin start URL, so the installed icon cannot be pointed at a look-alike host |
| T-01-23 | Information Disclosure | Offline shell exposing data after sign-out | accept | The precached shell contains no user data — it renders the auth-gated `App` which derives everything from the live session in `AuthContext`; offline with no valid session shows the auth form. Verified by Task 3 step 3 |
| T-01-24 | Denial of Service (usability) | iOS users seeing an inert install button | mitigate | `installMode()` branches to a purely instructional banner on iOS, unit-tested in Task 2, and Task 3 step 4 confirms on a real device that no dead Install control is rendered |
| T-01-SC | Tampering | `vite-plugin-pwa` install | mitigate | Version 1.3.0 verified against the live npm registry and cleared `[OK]` by the RESEARCH.md Package Legitimacy Audit; no `[ASSUMED]`/`[SUS]` package is introduced by this plan |
</threat_model>
